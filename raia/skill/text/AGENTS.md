# Responsible AI guidance for this repository (RAIA)

This product went through RAIA (Responsible AI Assistant). Its approved risk classification, ethical value requirements, RAI backlog and audits are in `raia-project/`.

Before you create, refine, prioritise, estimate, close or export any backlog item, user story or ticket for an AI feature in this repository:

1. Read the RAIA skill (`raia-responsible-ai/SKILL.md`, wherever this assistant keeps its skills) and follow it.
2. Read `raia-project/PROJECT_CONTEXT.md` for this project's facts.

In short: never lower a priority or a risk tier from those records; never mark something verified without evidence; leave risk acceptance and open decisions to a person; never rewrite the team's existing acceptance criteria (flag conflicts instead); and trace everything you add to a RAIA id (`EVR-n`, `RAI-n`, `US-n`, `AC-...`).

If this file was merged into an existing `AGENTS.md`, keep the paths above pointing at where the folders actually live.
