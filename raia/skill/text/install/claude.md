## What is inside

```
README_FIRST.md              This file
raia-responsible-ai.zip      The fixed part: the skill, the same for every project, never edited
raia-project/                The project part: this project's outputs (see its README.md)
```

## Install

1. In Claude, upload `raia-responsible-ai.zip` as a skill (skills must be enabled for your account).
2. Start a conversation or a project and attach `raia-project/PROJECT_CONTEXT.md`. Attach the CSV files too when you want the assistant to read the backlog or the roadmap.

In Claude Code, unzip `raia-responsible-ai.zip` into `.claude/skills/` and put `raia-project/` at the root of the repository.

If you cannot upload skills, download the format "One Markdown file" from RAIA instead and attach it to the conversation or add it to a project.
